# B7-1 웹 기반 AI 챗봇 서비스

로그인한 사용자가 웹 화면에서 질문하면 서버가 AI API를 호출해 답변을 보여주는 챗봇 서비스입니다. 질문과 답변은 PostgreSQL에 사용자별로 저장되고, 이전 대화를 이어서 물어볼 수 있습니다.

## 프로젝트 개요

- 문제 정의: 학습 중 생긴 질문을 바로 물어볼 곳이 필요하고, 물어본 내용을 나중에 다시 찾아볼 수 있어야 합니다.
- 타겟 사용자: 프로그래밍을 공부하는 학습자
- 핵심 시나리오: 회원가입, 로그인, 새 대화 시작, 질문 입력, 답변 확인, 이전 대화 이어서 질문, 내 대화 기록 조회

## 기술 스택

| 구분 | 사용 |
|---|---|
| 프론트엔드 | React, TypeScript, Vite |
| 백엔드 | Python, FastAPI |
| DB | PostgreSQL |
| 실행 | Docker Compose, Nginx |
